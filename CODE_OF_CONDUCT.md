# Contributor Covenant Code of Conduct

## Our Pledge

We pledge to make participation in **AirDelta** a welcoming, respectful, and harassment-free experience for everyone, regardless of background, identity, or experience level.

## Expected Behavior

- Use welcoming, inclusive, and constructive language.
- Focus on what is best for public health clarity, privacy, and code reliability.
- Accept and offer technical feedback gracefully.

## Unacceptable Behavior

- Harassment, personal attacks, derogatory comments, or trolling.
- Publishing others' private information (doxxing) or submitting deceptive/malicious code.

## Enforcement

Instances of abusive or unacceptable behavior may be reported to the repository maintainer via GitHub Issues or Security Advisories at https://github.com/AJAYMYTH/AirDelta.
